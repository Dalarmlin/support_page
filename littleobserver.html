LittleObserver｜小小觀察家

Photograph creatures, measure length with a reference object, train on-device AI, and export reports. 拍照觀察生物、用參考物量長度、訓練裝置端 AI，並匯出報告。
This page covers how to use the app, FAQ, permissions, and contact. 本頁提供使用說明、常見問題、權限說明與聯絡方式。

Quick Start / 快速開始

  1. EN: Create or select an observation project (e.g. tadpoles, insects).
    中：新增或選擇一個觀察專案（例如蝌蚪、昆蟲）。
  2. EN: In Parent Settings, add a reference object with a known real-world size (coin, ruler mark, etc.).
    中：到「家長設定」新增有真實尺寸的參考物（硬幣、尺上的刻度等）。
  3. EN: Tap “Observe today”, take or pick a photo with the creature and the reference object in frame.
    中：點「今天來觀察！」，拍攝或選取同時含生物與參考物的照片。
  4. EN: Mark the reference object on the photo so the app knows the scale, then measure the creature (tap head → tail, or use auto-detect if trained).
    中：在照片上標出參考物讓 App 知道比例，再量測生物（點頭→尾，或使用已訓練的自動辨識）。
  5. EN: Save today’s record. Use “Report” to export Excel / documents when ready.
    中：儲存今日紀錄；需要時到「整理報告」匯出試算表或文件。

FAQ / 常見問題

Why do I need a reference object? / 為什麼一定要設定參考物？

EN: Photos have no absolute size by themselves. A reference object with a known length (mm) lets LittleObserver convert pixels to real millimeters.
中：照片本身沒有絕對尺寸。有已知長度（公釐）的參考物，App 才能把畫素換算成真實毫米。

Does the app upload my photos? / 會不會上傳照片？

EN: No. Photos, measurements, and AI training data stay on this device. Camera / library access is only for choosing images you decide to use.
中：不會。照片、量測與 AI 訓練資料都只存在這台裝置。相機／相簿權限僅用於您選擇的影像。

Auto-detect does not find the creature / 自動辨識找不到生物

EN: Train the on-device AI first (Parent Settings → AI training) with a few clear photos, or measure manually by tapping head and tail. Good lighting and contrast help.
中：請先在「家長設定 → 生物 AI 辨識訓練」用幾張清楚照片訓練，或改以手動點頭、尾量測。光線充足、對比明顯會比較準。

Zhuyin (Bopomofo) appears on Traditional Chinese UI / 繁中介面有注音

EN: In Traditional Chinese, UI text uses the open-source font BpmfGenSenRounded, which shows Zhuyin beside characters for young readers. Switch language to Simplified Chinese / English / Japanese in Parent Settings if you prefer no Zhuyin.
中：繁體中文介面使用開源字型「源泉注音圓體」，會在字旁顯示注音，方便小朋友閱讀。若不需要注音，可到家長設定改為简体中文、English 或日本語。

How do I export a report? / 如何匯出報告？

EN: From the home screen, open “Report”, select observation records, then create Excel / Word / PPT as available in your build.
中：在首頁進入「整理報告」，勾選觀察紀錄後依版本提供的選項製作 Excel／Word／簡報。

Permissions / 系統權限

  • Camera / 相機： Photograph specimens for measurement and AI analysis on device. 拍攝生物照片以進行本機量測與分析。
  • Photo Library / 相簿： Optionally select an existing photo instead of taking a new one. 可選擇既有照片，不必每次重拍。
  • Network / 網路： Not required for core observation, measurement, or on-device AI. 核心觀察、量測與裝置端 AI 不需連網。

Privacy / 隱私

EN: LittleObserver is designed for local use. We do not operate a server that receives your photos or measurement records. See also our Privacy Policy.

中：LittleObserver 以本機使用為主，不會把照片或量測紀錄送到我們的伺服器。 詳見 隱私權政策。
